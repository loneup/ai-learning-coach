# ChatGPT Live 模式协议（实时陪练）

> 与所有科目共用。核心分工：**ChatGPT Live = 练习场（实时开口），Codex/档案 AI = 档案室（三件套 + git 落盘）**。Live 不读写档案，进度永远以档案三件套为准。

## 一、五个陪练模式（按科目/任务选用）

### 英语线

**1. 纠音陪练**（音标、朗读、读单词）
> 你是我的英语发音陪练。我读单词/句子给你听，只指出我最严重的 3 个发音问题，每个给 1 个口型要点和 1 个例句；不要逐词挑错，不要打断我的完整句子。

**2. 对话陪练**（话题库）
> 我们用英语聊【话题】。像普通对话者一样回应我，可以追问我；不要翻译、不要纠正我每一句。结束后只总结 3 个最值得改的表达和 1 个可以加进下次的句式。

**3. 复述评委**（精听材料）
> 我刚精听了【材料名】，现在用英语复述大意给你听。听完告诉我：我漏掉了哪些关键信息，哪里表达和原文差异最大，我的复述准确率大概多少。

### AI 线

**4. 费曼陪练**（学完一个模块）
> 我把今天学的【AI 知识点】讲给你听，你扮演零基础学员，问我 3 个最可能问的问题，并指出我哪句话讲得不够清楚；不要替我补充知识点，只负责提问和反馈。

**5. 口试自测**（3 追问）
> 今天学了【知识点】。请随机问我 3 道理解题，我答完你判断对不对；不对的只告诉我哪句说错了，让我自己重说一遍，而不是直接给答案。

## 二、每日闭环（四步，缺一步不算完成）

1. **准备（Codex，2 分钟）**：用 `assets/templates/live-session-card.md` 生成今天的 Live 练习卡——任务、材料、开场话术、证据要求；
2. **练习（Live，20–25 分钟）**：粘贴练习卡开场话术开练；条件允许同时录音，存档案 `证据库/`（英语线存 `证据库/英语/`）；
3. **总结（Live 内，2 分钟）**：结束时让 Live 输出固定摘要——纠出的 3 个问题、新学的 3 个表达、复述准确率自评、1 个下次改进点；
4. **落盘（Codex，3 分钟）**：把摘要发回 Codex，按「更新协议」落盘 PROFILE/SYSTEM/HANDOFF 并 git 提交。

## 三、证据纪律

- Live 口头评价（「你进步了」「发音不错」）**不是证据**；
- 有效证据 = 录音文件 + Live 练习摘要（已落盘）+ 痛点日志；
- 没有落盘 = 没练；AI 不能把「在 Live 聊过」升级为「已掌握/已会说」。

## 四、边界与隐私

- Live 是云端实时语音：不口述敏感业务数据、真实姓名、具体金额；练习卡只用泛化话题；
- Live 上下文有限、看不到档案：不要求它接续进度，只当陪练；进度以三件套为准；
- 一次只改最严重的 3 个问题，避免挫败；先开口，不追求完美。
