# 讲稿模板（演讲结构 + 故事框架）

## 一、演讲结构（结论先行）

1. **开场钩子（30 秒）**：一个问题 / 一个事实 / 一个画面，把听众拉进来；
2. **结论先行（一句话）**：今天我要讲的是【核心结论】；
3. **三个理由/要点（各带 1 个例子）**：
   - 要点 1：【…】——例子：【…】；
   - 要点 2：【…】——例子：【…】；
   - 要点 3：【…】——例子：【…】；
4. **回扣结论 + 行动号召（30 秒）**：所以【结论】；希望【听众做什么】。

> 一页讲稿只讲一件事；每句话要么支撑结论、要么举例，否则删。

## 二、故事框架（四段）

1. **场景**：什么时候、在哪、和谁（1 句话建立画面）；
2. **冲突**：遇到了什么问题/卡在哪（这是故事的钩子）；
3. **转折**：做了什么选择/什么意外改变局面；
4. **收获**：结果 + 我学到了什么（留给听众的「带走物」）。

> 讲故事的检查清单：有没有画面？有没有悬念？有没有转折？听众听完带走什么？
