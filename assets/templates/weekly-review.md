# 每周复盘（10 分钟）

> 每周五或周末做一次，结果写进 PROFILE 证据表与 HANDOFF「最需要注意」，然后 git 提交。

## Week N（2026-XX-XX ~ XX）

### 1. 本周真正留下了什么？

- 录音证据：【条数 + 文件】；
- Anki 牌组：【新卡/复习数】；
- 痛点日志：【条数 + 最有用的一条】；
- 产出物：【任务/项目 + 链接】。

### 2. 哪个环节卡住了？

- 卡点：【如：音标 [θ] / 精听听不清连读 / 话题说不满 1 分钟】；
- 原因：【太累？太难？太无聊？还是方法不对？】。

### 3. 下周只改哪一件事？

- 下周行动：【一句话，只改一件】；
- 成功标准：【怎么算改成了】。
